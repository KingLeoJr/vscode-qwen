# Qwen - VS Code Extension

Embed **[Qwen](https://qwenlm.ai/)** directly into your VS Code sidebar. This extension allows you to interact with Qwen without leaving your editor.

![Banner](images/banner.png)

---

## Features

* **Embed Qwen** : Open Qwen in a Webview panel within VS Code.
* **Customizable URL** : Configure the URL of the Qwen instance to embed.
* **Persistent Session** : Saves your session URL so you don't have to reconfigure it every time.
* **Easy Access** : Open the webview with a single click from the status bar or command palette.

---

## Installation

1. Open  **VS Code** .
2. Go to the **Extensions** view by clicking on the Extensions icon in the Activity Bar or pressing `Ctrl+Shift+X`.
3. Search for  **"Qwen"** .
4. Click **Install** to add the extension.

Alternatively, you can install the extension from the [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Kingleo.qwen).

---

## Usage

### Open Qwen

1. Click the **Qwen icon** in the Activity Bar.
2. Alternatively, use the **Command Palette** (`Ctrl+Shift+P`) and search for `Open Qwen`.

### Customize the URL

1. Open **Settings** (`Ctrl+,`).
2. Search for `Qwen`.
3. Update the `URL` field with any URL (e.g., `https://qwenlm.ai/` or a custom URL).

---

## Commands

| Command       | Description            |
| ------------- | ---------------------- |
| `qwen.open` | Open the Qwen Webview. |

---

## Configuration

| Setting      | Default Value          | Description                                                 |
| ------------ | ---------------------- | ----------------------------------------------------------- |
| `qwen.url` | `https://qwenlm.ai/` | The URL of the Qwen instance to embed. This can be any URL. |
